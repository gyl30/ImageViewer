## Standards

第一段提出一项范围质疑：`main.cc` 设置程序图标、版本和帮助是否属于本轮禁止的 UI 改动。主代理未采纳为违规：用户明确要求应用图标、桌面集成和候选识别，此处只有应用元数据，没有浏览控件、渲染、缓存或布局变化。

另有一项可能的 Duplicated Code 判断：安装路径同时出现在 CMake、包白名单与文档。主代理保留现状：白名单是独立验证边界，若从被测安装规则生成则不能发现开发内容被误装；文档用于解释安装契约。没有因此引入包装层或生成机制。

增量审查未发现硬性规范问题或可确认的12类异味。`wait_window` 用于主窗口、文件/目录对话框及图片窗口，具有独立的等待职责，不属于单次空转包装。规范导出、实际大小采集和 wmctrl 工具依赖均在发布脚本、CI 与文档对应更新。

主代理复核：只有发布元数据触及 main.cc，其他原产品模块没有变化；无私有可见性提升、兼容分支、用户工作区覆盖、push 或 Release 操作。Shell 语法与 diff 空白检查通过。
