# 0.1.0-rc.1 Linux 本地发布验收

本地 DEB/RPM 候选通过构建、回归、干净用户空间安装和运行验收，可以进入许可证确认与远程 CI 验证。**许可证尚未确定，当前不能对外发布。** 没有推送、打标签、上传二进制或创建 GitHub Release；候选未签名。

## 版本与改动范围

任务起点为 `c0876d3`，main 与 origin/main 一致，工作区干净。受测源码为 `3a276dacb63cf03179533725eb877ce05c7a2ad1`，SOURCE_DATE_EPOCH 为 `1792969845`。本报告及后续文档提交不改变该候选的受测源码身份。完整机器记录见 [manifest.json](manifest.json)。

已阅读[上一轮最终验收](../../final-acceptance-2026-10-25.md)。保留其 Linux/Xorg 单屏、静态 DPI、真实素材和两小时长测结论及限制；此次没有重新运行大型性能矩阵，也不将 Qt6.9.3 的性能数字当成本次系统 Qt 包的测量值。

本轮修改仅包含 Release/install/CPack、桌面入口、复用已有 SVG、程序身份和版本帮助、发布工具、CI 与文档。原有扫描、图片加载、缓存、瀑布流、预览及主窗口实现均未修改；没有新增产品配置、线程、缓存或依赖框架。`main.cc` 只增加桌面身份、图标、版本和帮助解析，没有修改浏览操作。

## 依赖、版本与兼容性

使用系统共享 Qt 与图像插件，主 ELF 动态依赖无缺失、无开发机 RPATH、无 QtTest；实际进程映射确认加载系统的 xcb、SVG 图标引擎、JPEG、WebP、GIF 插件。PNG/BMP 也通过实际开图验证。发行版插件包可能附带其他格式，应用仍只声明现有五格式。

完整直接依赖和目标系统解析清单见[依赖说明](dependencies.md)。相对于本次最小官方基础镜像，安装应用和共享依赖的声明大小增量分别约266.27、276.55、475.60MiB；这不是包大小、RSS、下载量或 `du` 实测。已有 Qt 桌面的增量可能更小，不据此宣称本次降低了进程内存或磁盘使用。

工程最低支持版本设为**实测 Qt6.4.2**。原 Qt6.2.4 已因既有 `QDir::mkdir` 权限接口真实编译失败，[失败日志](qt62-build-failure.txt)保留；未修改核心去兼容旧 Qt。该接口从6.3引入，但未测试6.3，因此不承诺该版本。CMake 声明的最低版本也不意味着 Fedora 生成的包可在 Qt6.4 系统运行：本 RPM 自动依赖包含 `Qt_6.10` 符号，只确认 Fedora43。

其他发行版、架构、旧 Fedora、原生 Wayland、真实跨屏和动态硬件 DPI 均未验证。静态三档 DPI 的已有真实单屏结果属于前轮 Qt6.9.3，不能冒充本轮两个系统 Qt 的实机复验。

## 可重复构建与测试

每套构建器固定镜像 ID，用同一提交的两份独立 `git archive` 导出、相同 SOURCE_DATE_EPOCH、两个全新容器及输出目录分别完整编译、测试、安装暂存和打包。两份 DEB、两份 RPM 及各自暂存 ELF 均已实际逐字节比较一致。完整包一致覆盖 RPM 后处理后的最终 ELF，干净安装后另核对真实程序摘要。[Debian 复建记录](debian12/reproducibility.json)、[Fedora 复建记录](fedora43/reproducibility.json)。

复现范围是同一已解析构建器、源码提交、时间基准和架构。基础镜像摘要固定，但 apt/dnf 仓库仍会更新；跨日期重新创建构建器得到新依赖时，不保证字节一致。构建器 ID 与完整包版本已记录并保留本地镜像。候选的规范导出和构建入口见[发布流程](../../linux-release.md)。

## 验收中确认并处理的问题

| 事实 | 原因与处理 | 验证 |
|---|---|---|
| Fedora 精简系统未安装许可状态说明 | 官方 `tsflags=nodocs` 跳过普通文档，改为 `%license` 文件属性 | 最终清单包含该文件；卸载成功 |
| RPM 默认重复打包哈希不同 | 构建主机和时间进入头部，固定主机标记及 SOURCE_DATE_EPOCH | [原型诊断](rpm-before-reproducibility.json)；最终双次完整构建相同 |
| 同源码工作树与 Git 导出的 RPM 仍不同 | RPM 保留早于 epoch 的资源 mtime，规范输入统一使用 Git 导出 | [跨导出诊断](rpm-cross-export.json)；最终两份独立导出相同 |
| 暂存 ELF 大小不能代表 RPM 分发 ELF | 发行版 BRP 还会处理程序 | 新增安装后 stat/SHA256，与包内摘要核对 |
| Ubuntu GUI 工具偶发 `X_QueryTree BadWindow` | 递归查询瞬态 Qt 子窗口，替换为 WM 顶层客户端列表 | 三套最终干净运行全部通过 |
| 测试工具缺失、WM/输入焦点竞争、Qt 插件日志格式差异 | 明确工具依赖、等待 WM 就绪、同步焦点、读取真实进程映射 | 三套最终完整脚本通过 |

这些是本轮发布流程和验收工具问题，修正前的中间运行不计入通过结果；没有据此修改图片浏览核心。
